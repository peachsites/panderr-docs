# Integrations & Partnerships

Panderr is being developed as a migration and publishing platform that can work alongside the tools businesses and web professionals already use.

## Integration philosophy

Panderr's integration strategy is based on three ideas:

1. **Reduce migration friction.** Existing websites, content, and design work should be reusable.
2. **Preserve user choice.** Customers should be able to move between tools and providers without automatically losing the website they already invested in.
3. **Connect design to deployment.** Integrations should help move work from source material or design systems into an editable, publishable website workflow.

## Current integrations

Panderr's integrations make its website migration capabilities available within the tools people already use. Each integration starts a migration and hands off to Panderr, where the preview, editing, purchase, and publishing happen.

- **Panderr – Website Migration (WordPress plugin):** starts a migration from inside a WordPress dashboard, sending the site's public address and name to Panderr. Preserve, Improve, or Redesign is chosen in Panderr.
- **Panderr for ChatGPT (plugin):** begin a website migration inside ChatGPT, then continue in Panderr to preview, edit, and manage the site.
- **Panderr for Claude (connector):** published in [Anthropic's Claude Connector Directory](https://claude.ai/directory/panderr) (a community connector by PeachSites, LLC). It connects to Panderr's MCP server (https://panderr.com/mcp?partner=claude) and returns a link that starts a migration preview. No sign-in is required.

## Current partnership areas

Panderr is exploring and developing relationships across several categories:

### Cloud infrastructure

Cloudflare supports Panderr's deployment, serverless application, data, and asset-storage needs. See [Cloudflare Platform](cloudflare-platform.md).

### Design platforms

Design-platform integrations can help bridge the gap between visual design and deployable websites. Panderr is interested in workflows that make existing design assets easier to translate into editable website projects.

### CMS and website ecosystems

Panderr's migration model is relevant to businesses moving away from or between website platforms, including CMS-based sites and hosted website builders.

### Agencies and service providers

Panderr can support professionals who need a repeatable way to migrate, improve, redesign, and publish client websites while preserving the distinction between client content, design intent, and deployment infrastructure.

## Partner use cases

Potential partner workflows include:

- importing an existing website into Panderr
- preserving an existing design during a platform move
- modernizing an imported website while retaining brand and content
- using design-system or template inputs as part of a redesign
- preparing migrated sites for Cloudflare-backed deployment
- supporting agency workflows across multiple client projects

## Public documentation scope

This repository documents Panderr's product direction and public integration concepts. It does not expose private partner agreements, unreleased implementation details, credentials, internal APIs, or proprietary migration logic.
